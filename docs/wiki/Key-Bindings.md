# Key Bindings

All default key bindings for Zeta. Most can be customized in `config.toml` under `[keymap]`.

---

## Global

| Key | Action |
|---|---|
| `F10` / `q` | Quit Zeta |
| `Shift+P` | Open command palette |
| `Ctrl+O` | Open settings panel |
| `Tab` | Switch active pane |
| `Alt+F` | Open File menu |
| `Alt+N` | Open Navigate menu |
| `Alt+V` | Open View menu |
| `Alt+H` | Open Help menu |

---

## Workspace Switching

| Key | Action |
|---|---|
| `Alt+1` | Switch to workspace 1 |
| `Alt+2` | Switch to workspace 2 |
| `Alt+3` | Switch to workspace 3 |
| `Alt+4` | Switch to workspace 4 |
| `Shift+1` | Switch to workspace 1 (terminal fallback) |
| `Shift+2` | Switch to workspace 2 (terminal fallback) |
| `Shift+3` | Switch to workspace 3 (terminal fallback) |
| `Shift+4` | Switch to workspace 4 (terminal fallback) |

---

## File Pane Navigation

| Key | Action |
|---|---|
| `↑` / `↓` | Move cursor |
| `PgUp` / `PgDn` | Page up / page down |
| `Home` / `End` | Jump to first / last entry |
| `Enter` | Open directory / open file in editor |
| `Backspace` | Go to parent directory |
| `Alt+←` | Navigate backward in directory history |
| `Alt+→` | Navigate forward in directory history |
| `Space` / `Ins` | Toggle mark on current file |

---

## File Operations

| Key | Action |
|---|---|
| `F5` | Copy |
| `F6` | Rename (inline) |
| `Shift+F6` | Move to opposite pane |
| `F7` | New directory |
| `F8` | Delete |
| `Ins` | New file |
| `Ctrl+H` | Toggle hidden files |
| `Ctrl+C` | Copy path(s) to clipboard |

---

## Panels and Views

| Key | Action |
|---|---|
| `F2` | Toggle integrated terminal |
| `Ctrl+\` | Toggle integrated terminal (alternate) |
| `F3` | Toggle file preview panel |
| `Alt+F3` | Focus preview panel |
| `F4` | Open selected file in editor |
| `F9` | Toggle git diff mode |
| `Ctrl+D` | Toggle git diff viewer |

---

## Editor

| Key | Action |
|---|---|
| `Ctrl+S` | Save file |
| `Ctrl+Q` | Close editor |
| `Ctrl+Z` | Undo |
| `Ctrl+Y` / `Ctrl+Shift+Z` | Redo |
| `Ctrl+F` | Open search bar |
| `Enter` / `n` | Next search match |
| `Shift+Enter` / `N` | Previous search match |
| `Esc` | Close search / cancel |
| `Ctrl+A` | Select all |
| `Ctrl+C` | Copy selection |
| `Ctrl+X` | Cut selection |
| `Ctrl+V` | Paste |
| `Shift+↑/↓/←/→` | Extend text selection |

---

## Git Diff Viewer

| Key | Action |
|---|---|
| `↑` / `↓` / `j` / `k` | Navigate file list |
| `PgUp` / `PgDn` / `d` | Scroll diff content |
| `Tab` | Switch focus between file list and diff |
| `Ctrl+D` | Exit diff viewer |
